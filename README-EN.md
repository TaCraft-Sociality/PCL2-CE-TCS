# PCL TCS 

[Upstream repository](https://github.com/Meloong-Git/PCL)


</div>

> This directory contains the **source code of PCL TCS (the TCS client launcher), blue edition**, a fork of
> PCL CE (PCL Community Edition) maintained by the TCS server team.
> Main customisations over upstream: blue icon, left vertical navigation, built-in browser entries for
> Community / Skin Site / Bilibili, a "Multiplayer" page based on the third-party open-source Terracotta
> (the same approach as HMCL, independent of the official PCL lobby service), offline / third-party
> verification login available right at the first launch, and notices rewritten in the TCS style.
> Upstream PCL CE and PCL remain copyright their respective authors.

PCL CE is a community fork of the open-source PCL, featuring functions and improvements not yet made in the mainline!

Version numbers of the community edition do not strictly correspond to the mainline, and please do not report community-edition issues to the official repository.

Enjoy!

## 💻 Supported platforms

| Operating system | Support | Requirements |
|---|---|---|
| Windows 10 1809 (17763) or newer | ✅ Fully supported | [.NET 10 Desktop Runtime](https://get.dot.net/10) |
| Windows 8 - Windows 10 1809 (17763) | ⚠️ Should run, community support at our discretion | [.NET 10 Desktop Runtime](https://get.dot.net/10) |
| Windows 7 or older | ❌ Not supported | / |
| macOS / Linux / other OS | ⚠️ Cross-compilation development support only | [.NET 10 SDK](https://get.dot.net/10) |

**✅ Fully supported**: we provide as much support as possible, but you must make sure the launcher is up to date.

**⚠️ Should run, community support at our discretion**: PCL TCS should run on these platforms, but full functionality is not guaranteed. You may need to upgrade to a fully supported OS version for further community support.

**❌ Not supported**: PCL TCS has low usability on these platforms and may not even open. Please upgrade your OS to use PCL TCS.

**⚠️ Cross-compilation development support only**: the PCL TCS source code can be compiled on macOS and Linux, but cannot run there directly. As a developer you can work on these platforms and then move the build output to Windows for testing.
