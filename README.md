# PCL TCS

[上游存储库](https://github.com/Meloong-Git/PCL)

</div>

> 本目录为 **PCL TCS（TCS 客户端启动器）源码**：由 TCS 服务器团队基于 PCL CE（PCL Community Edition）二次开发。
> 相对上游的主要定制：蓝色图标、左侧竖向导航、内置「社区 / 皮肤站 / B站」浏览器入口、
> 基于陶瓦（Terracotta）的「联机」页面（与 HMCL 同款方案，不依赖 PCL 官方联机服务）、
> 首次启动即可用离线 / 第三方验证登录，以及 TCS 口径的文案。
> 上游 PCL CE 与 PCL 的版权归其各自作者所有。

PCL CE 是基于 PCL 开源代码二次开发的社区版本，包括了主线暂未制作的功能和改进！

社区版的版本号与主线并非严格对应关系，也请不要向官方仓库反馈社区版问题。

欢迎大家来用用看！

## 💻 支持平台

| 操作系统 | 支持情况 | 环境要求 |
|---|---|---|
| Windows 10 1809 (17763) 或更高 | ✅ 完整支持 | [.NET 10 Desktop Runtime](https://get.dot.net/10) |
| Windows 8 - Windows 10 1809 (17763) | ⚠️ 理论能跑，酌情提供社区支持 | [.NET 10 Desktop Runtime](https://get.dot.net/10) |
| Windows 7 或更低版本 | ❌ 不支持 | / |
| macOS / Linux / 其他操作系统 | ⚠️ 仅跨平台开发支持（交叉编译） | [.NET 10 SDK](https://get.dot.net/10) |

**✅ 完整支持**：尽可能提供一切相关支持，但必须确保启动器为最新版本。

**⚠️ 理论能跑，酌情提供社区支持**：PCL TCS 应该可以在这些平台上运行，但不保证功能完全可用。你可能需要升级到完整支持的系统版本以获得进一步社区技术支持。

**❌ 不支持**：PCL TCS 在这些平台的可用性较低，甚至压根打不开。请升级操作系统以使用 PCL CE。

**⚠️ 仅跨平台开发支持（交叉编译）**：PCL TCS 的源代码可以在 macOS 与 Linux 平台编译，但无法直接运行。作为开发者，你可以在这些平台上进行开发，然后将编译产物转移到 Windows 系统测试。
